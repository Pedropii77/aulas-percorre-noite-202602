## HTMl - HyperText Markup Language
O HTML é uma lingugaem de marcação de texto, ou seja, seu proprósito é estruturar textualmente uma páigna da Web/Documento.

## Elementos ou tags
Para estruturar um documento HTML utilizamos tags/elemenos, por exemplo, para indicarmque um texto é uma parágrafo utilizamos a tag < p >texto do parágrafo< /p >
Existem tags que tem abertura < p > e fechamento < /p >, mas também existem tags "autofechantes" que não possuem fechamento, como a tag < img > de imagem.

### Exemplos de tags:
 - p : parágrafro
 - h1 : Títilo principal
 - h2 : Título secundário
