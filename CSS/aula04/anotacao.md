# Box Model
O CSS enxerga os elementos do HTML como caixas que possuem algumas propriedades.

## Margin
Margem é o espaço que distancia um elemento do outro, ou seja, é essa medida que faz um parágrafo ir para longe de uma imagem.

## Border
Para contornar um elemento podemos configurar uma borda, a borda nada mais é do que uma linha em volta do elemento que fica entre a margin e o padding.

## Padding
Se a margin é o espaço externo de um elemento, o padding é o espaço interno, ele separa o conteúdo da borda e da margin.
